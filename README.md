Totem de tendimento 🍔

Sistema de autoatendimento desenvolvido como projeto acadêmico, com o objetivo de facilitar a realização de pedidos por meio de uma interface intuitiva e interativa.

A aplicação permitirá visualizar produtos organizados por categorias, adicionar e remover itens do carrinho, ajustar quantidades, calcular automaticamente o valor total e selecionar formas de pagamento, além de apresentar um resumo e a confirmação do pedido.

Tecnologias previstas:
- HTML5, CSS3 e JavaScript — Frontend
- PHP — Backend e regras de negócio
- PostgreSQL e SQL — Banco de dados
- Git e GitHub — Versionamento e colaboração

O projeto será desenvolvido em equipe como parte da formação técnica em Desenvolvimento de Sistemas, com foco na integração entre frontend, backend e banco de dados, além da aplicação de boas práticas de programação e segurança.
